# Assets y licencias de personajes

## Universal Animation Library (UAL1 y UAL2)

Los maniquíes y animaciones de `Content/Characters/AnimationLibraries/UAL1` y `UAL2` provienen de los archivos `Universal Animation Library[Standard].zip` y `Universal Animation Library 2[Standard].zip` proporcionados para este proyecto.

Los archivos `License.txt` incluidos en ambos ZIP identifican la licencia **CC0 1.0 Universal** y acreditan los modelos a **@Quaternius**. La licencia permite copiar, modificar y distribuir el material. Referencias:

- [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/)
- [Universal Animation Library](https://quaternius.com/animviewer.html)

La integración actual usa el maniquí y un subconjunto de animaciones compartidas para el prototipo. Esto no significa que los 13 personajes tengan modelos, movimientos o kits visuales finales propios.
