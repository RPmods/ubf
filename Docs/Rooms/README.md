# Salas

El prototipo permite iniciar una arena local de 1v1, 2v2 o 3v3 y elegir si los huecos se dejan vacíos, se completa el equipo rival o se rellenan ambos equipos con bots.

Pendiente: sesión/lobby con jugadores reales, estados de sala, asignación explícita de espacios, cantidad configurable de bots, equipos mixtos, selección repetible de personaje, salida/cancelación y reinicio. La configuración local actual no es un sistema online de salas.
