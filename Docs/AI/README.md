# IA

La versión actual contiene un bot local básico: persigue al enemigo más cercano, ataca al aproximarse y usa Q/E/F según el gauge. El bot controla el mismo personaje de combate que el jugador.

Pendiente: perfil de comportamiento por personaje, dificultades Easy/Normal/Hard, reacción imperfecta, estados tácticos y prioridades del Golem Mode. No hay todavía lógica observada para GoldenBearer o Master Golem.
