# Controles

Actualmente el personaje enlaza acciones heredadas (`BindAction`/`BindAxis`) y los nombres de acciones del HUD están fijos. La expansión requiere acciones Enhanced Input (`IA_SkillPrimary`, `IA_SkillSecondary`, `IA_Ultimate`, entre otras), remapeo local persistente, detección de conflictos y HUD actualizado con la tecla asignada.

Valores deseados: LMB atacar, RMB cargar, LMB+RMB agarrar, Ctrl dash, Space saltar, Q habilidad primaria, E secundaria y F Ultimate.
